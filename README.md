# 趋势全景 · 股票分析
一款本地运行的 **A 股「一屏式趋势全景」分析软件**。与同花顺等通用软件不同，它把一只股票的**价格技术趋势 + 基本面趋势 + 资金趋势**全部整合进一个页面，不用来回切换，打开即看懂趋势全貌。

## 核心特色
- **一屏全景**：多周期趋势（日/周/月）→ 技术指标 → K线 → 资金流 → 基本面 → 综合结论，全部在一屏内呈现
- **结论先行**：不堆指标数字，直接给出趋势方向和强度判断，以及一句话综合结论（偏多 / 中性 / 偏空）
- **自选股管理**：本地保存你的自选股，实时显示行情
- **K线周期切换**：日线 / 周线 / 月线 一键切换
- **免费数据源**：使用腾讯 / 东方财富公开接口，无需注册、无需付费 Key

## v1.6.0 新增
- **高适配池参数化**：市值门槛 100亿 / 50亿 / 30亿 三档可调（「推送设置 → 高适配池」）。门槛越低池子越大，越易覆盖市值中小的大牛股（回测：30亿池收益 +356% vs 100亿池 +19%）。池子过滤 = 市值 + 日均成交额≥1亿 + 波动率适中 + 剔除ST/次新
- **牛熊离场切换**：牛市（进取）用「破MA20+大盘转弱双确认」让利润奔跑；熊市（稳健）用「破线即走」控回撤；自动模式按环境评分自动选。持仓 / 模拟持仓 / 个股页离场提示自动跟随。**-10%回撤止损线始终生效**
- **高适配池动态更新**：一键「重建高适配池」= 按新门槛重筛池子 + 拉实时K线评估流动性/波动 + 重建行业指数（约1-3分钟），重建后重新扫描即生效
- **今日机会每日扫描**：每日收盘 15:35 自动扫描高适配池，出现机会的股票（抄底/趋势通道，最高3★），可微信推送
- **模拟持仓跟踪**：把今日机会虚拟买入，每日按离场规则跟踪，20日实验看整体收益
- **我的持仓**：登记真实买入价/日期，只有持仓股显示卖出/止损提示（推荐页始终是买入视角）
- **在线更新**：右上「检查更新」→「立即更新」，免重新解压安装

## 一屏内容详解
| 区块 | 内容 |
|---|---|
| 股票信息栏 | 现价、涨跌、今开/昨收/最高/最低、成交量、成交额、换手率、PE、PB、总市值 |
| 多周期趋势条 | 日线/周线/月线各自的方向（上升/下降/震荡）和强度（强/中/弱） |
| 层级共振 | 大盘 → 行业 → 个股 三层趋势方向与共振状态 |
| 技术指标 | MACD（金叉/死叉/多头/空头）、RSI(14)、量能 |
| K线走势 | K线 + 均线 + 成交量 + 跳空/形态信号标记 + 支撑阻力 + 趋势线，支持日/周/月切换 |
| 主力资金 | 近20日主力资金净流入柱状图 |
| 基本面趋势 | 营收/净利绝对值柱状图 + 同比% + 毛利率多期走势 |
| 综合结论 | 综合价格+资金+基本面，自动生成评级和一句话判断 |

## 运行环境要求
- **Python 3.10 及以上**（3.10/3.11/3.12 均可）
- 系统：Windows / macOS / Linux 均可
- 需要联网（数据来自网络接口）

## 快速启动（推荐）
### Windows
双击运行 **`启动股票分析.bat`**，脚本会自动安装依赖、启动服务并打开浏览器。
### macOS / Linux
```bash
cd 项目目录
chmod +x start.sh
./start.sh
```
首次运行会自动安装依赖（flask / requests / pandas），之后每次直接启动。
启动成功后浏览器会自动打开 **http://127.0.0.1:5000**，即可使用。

## 手动启动

```bash
# 2. 启动

```
浏览器访问 http://127.0.0.1:5000

## 使用说明
1. **添加自选股**：顶部输入框输入「股票代码」（如 600519）或「股票名称」（如 茅台），回车或点 + 添加
2. **查看个股**：点击左侧自选股列表中的任意股票，右侧立即显示完整趋势全景
3. **切换周期**：K线图右上角可切换 日线/周线/月线
4. **调整高适配池**：右上「推送设置 → 高适配池」选市值门槛 → 点「重建高适配池」→ 「今日机会」→「▶ 扫描」
5. **删除自选**：鼠标悬停自选股，点右侧 × 删除
6. **刷新数据**：股票信息栏右侧 ↻ 按钮可重新加载当前股票

## 常见问题
**Q：打开页面空白或数据加载失败？**
A：通常是数据源临时抖动。点击股票信息栏右上角的「↻ 重试」按钮重新加载即可。
**Q：为什么行情价格和券商软件略有差异？**
A：本软件使用腾讯/东财公开接口，价格可能存在极小的延迟（通常秒级），适合趋势分析，不适合超短线精确盯盘。
**Q：数据会收费吗？**
A：不会。全部使用公开免费接口，无任何收费项。
**Q：自选股会丢失吗？**
A：自选股保存在项目目录的 `watchlist.json` 文件中，不会丢失。备份整个项目目录即可。
