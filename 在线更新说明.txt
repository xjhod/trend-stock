【这个功能解决什么】
  以后我每次优化完，你只需打开软件 → 点右上角「检查更新」
  → 点「立即更新」，代码自动下载替换，数据(自选股/机会/推送设置)全部保留。
  再也不用重新下载 zip 解压覆盖。

【一、一次性设置（约10分钟）】

  第1步：建 GitHub 仓库（免费）
    1. 打开 https://github.com ，注册/登录账号
    2. 右上角 + → New repository
    3. Repository name 填: trend-stock
    4. 选 Public（公开），不要勾选任何初始化文件
    5. 点 Create repository

  第2步：把代码推上去（在项目文件夹里操作）
    1. 下载安装 Git: https://git-scm.com/download/win （一路下一步）
    2. 打开命令行(cmd)，进入项目文件夹:
         cd 你的项目文件夹路径
    3. 依次执行:
         git init
         git add .
         git commit -m "init"
         git branch -M main
         git remote add origin https://github.com/你的用户名/trend-stock.git
         git push -u origin main
        （你的用户名 = GitHub 账号名；推送时提示输入账号密码，
          密码处填 GitHub 的 Personal Access Token，
          生成方法: GitHub→头像→Settings→Developer settings→
          Personal access tokens→Tokens(classic)→Generate new token
          →勾选 repo→生成并复制）

  第3步：填写更新源地址
    1. 用记事本打开项目文件夹里的 update_config.json
    2. 把里面的地址改成:
       "update_url": "https://raw.githubusercontent.com/你的用户名/trend-stock/main/latest.json"
    3. 保存

  第4步：发布 latest.json（版本清单）
    每次发布新版本，把项目里的 latest.json 推上去即可:
         git add latest.json && git commit -m "v新版号" && git push

  完成！以后打开软件右上角「检查更新」即可自动更新。

【二、以后我优化完，你需要做的】
  1. 打开软件（或点右上角「检查更新」）
  2. 弹出"发现新版本"→ 点「立即更新」
  3. 等几秒提示"更新完成" → 关闭窗口重新双击启动
  4. 完成，用上最新版

【三、原理说明（可选阅读）】
  · 更新源 = GitHub 仓库里的 latest.json（记录最新版本号和下载地址）
  · 软件启动时静默检查一次，有新版才提示，不打扰
  · 更新只替换代码文件(.py/.html/.js 等)，你的自选股 watchlist.json、
    机会数据 daily_signals.json、推送配置 config.json 等一律保留不动
  · 数据文件不会推上仓库（.gitignore 已排除），仓库里只有代码
  · 若不想让代码公开，可用 GitHub 私有仓库，但需额外配置 token，
    公开仓库最简单且代码不含你的隐私数据

【四、常见问题】
  Q: 点检查更新提示"未配置更新源"
  A: update_config.json 里的地址还没填对，按第3步核对
  Q: 提示"检查更新失败"
  A: 网络问题或地址不对，把提示发给我排查
  Q: 更新到一半失败，软件还能用吗
  A: 能。更新是逐个文件替换，失败不会清空原有代码；
     重新点一次更新即可
