  趋势全景 · 股票分析（本地版）使用说明
════════════════════════════════════════════════
【一、安装（只需一次）】
  1. 安装 Python 3.10+（若电脑没有）
     · 下载: https://www.python.org/downloads/
     · 安装时【务必勾选】"Add Python to PATH"，
       否则双击启动脚本会提示找不到 Python
  2. 解压本压缩包到任意文件夹（路径建议不要含中文和空格，
     如 D:\trend-stock）
  3. 双击「启动股票分析.bat」
     · 首次运行会自动安装依赖（约1-2分钟，国内镜像加速）
     · 之后每次双击即可启动
【二、启动后】
  · 浏览器自动打开 http://127.0.0.1:5000
  · 若未自动打开，手动在浏览器输入这个地址
  · 关闭黑色命令窗口 = 关闭软件
【三、功能一览】
  · 左侧「自选股」：添加/导入你的股票
  · 左侧「高适配」：市值≥1000亿的机构白马池，按行业分类
  · 左侧「今日机会」：每日收盘后自动扫描高适配池，
    出现机会的股票（★★★/★★强机会、★观察）
  · 右上「推送设置」：配微信(Server酱/PushPlus)后可每日
    自动推送机会；每日 15:35 自动扫描
  · 点任意股票 → 一屏看全：多周期趋势、共振、技术指标、
    K线(含跳空/形态标记)、资金、基本面、营收净利柱状图
【四、今日机会 · 推荐逻辑（v1.5.0）】
  ── 前置 ──
  · 只扫描「高适配股票池」(默认182只：大市值、低波动)，
    垃圾股不参与，保证形态信号可信
  · 池子可在「推送设置 → 高适配池」里按市值门槛动态重建
    （v1.6.0，见下）
  ── 第一步：大盘门卫（每只必过）──
    大盘环境不行 → 全部不推荐（这正是弱市自动空仓的原因）
    1. 大盘不在下跌（方向≠下跌，允许横盘）
    2. 大盘不在顶部（近5日不跌超1.5%）
    3. 大盘非系统性转弱（均线死叉+5日跌2%）
  ── 第二步：双通道扫描 ──
  通道A · 抄底（超跌反弹，同时满足4条）：
    1. 60日回撤≥20%（超跌）
    2. 行业不在下跌
    3. 企稳：不再创新低 + 收盘站上MA10（不接飞刀）
    4. 有看涨形态且形态质量合格（位置+量能配合）
    → 星级：基础1★ + 深超跌(≤-25%)+1★ + 大盘弱+1★，最高2★
  通道B · 周线趋势（真趋势）：
    1. 主判据：周线多头排列（周MA5>10>20且收盘>周MA10）
       ——必须是周线级真趋势，日线短均线多头不算
    2. 行业过滤：行业不在下跌/不在顶部/未破位(>MA20)/
       不在高位(60日涨幅≤25%)/行业周线多头(行业趋势向上)
    3. 个股防追高：距60日高≥5%、RSI<70、60日涨幅≤60%、
       乖离MA20≤10%
    4. 评分门槛≥2分：
       · 周线多头基础1分
       · 日线深回调 +1分（实证最佳买点）
       · 三层共振(大盘↑+行业↑+个股↑) +1分
       · 看涨形态 +1分
    → 星级最高3★（含周线确认的真趋势）
  ── 第三步：市场环境模式（可调）──
  · 自动/稳健模式：环境评分低于阈值 → 空仓不推荐
  · 进取模式：按建议仓位标注（可自己在「设置」里调）
  ── 第四步：排序展示 ──
  · 按星级降序（3★→1★），同星按当日涨幅
  一句话：大盘合格 → 抄底(超跌+企稳+形态) 或
           趋势(周线真趋势+行业向上+不追高) → 环境把关 → 按星级排序
【四B、v1.6.0 新增：池子参数化 + 牛熊离场切换 + 动态更新】
  ── 1. 高适配池参数化（市值门槛可调）──
  · 打开软件 → 右上「推送设置」→「高适配池」
  · 市值门槛三档：100亿（机构白马，默认）/ 50亿 / 30亿
  · 门槛越低池子越大，越容易覆盖到市值中小的大牛股；
    回测实证：30亿池收益显著优于100亿池（+356% vs +19%）
  · 池子成员过滤规则（研究验证）：市值≥门槛 + 近60日日均成交额
    ≥1亿(流动性) + 年化波动率0.1~0.7(剔除太妖/太死) + 剔除ST/次新
  ── 2. 牛熊离场切换（持仓/模拟持仓自动跟随）──
  · 牛市(进取模式)：破MA20 + 大盘转弱 双确认才离场
    → 让利润奔跑，避免卖飞（实证牛市双确认收益更高）
  · 熊市(稳健模式)：破MA20 即离场
    → 及时止盈控回撤（实证熊市破线即走更稳）
  · 自动模式：程序按环境评分自动选择（评分≥阈值→双确认，否则破线即走）
  · 无论哪种模式，回撤-10%止损线始终生效（风控底线）
  · 持仓/模拟持仓的离场建议会显示当前采用的离场风格
  ── 3. 动态更新（一键重建池子）──
  · 「推送设置 → 高适配池 → 重建高适配池」
  · 按新门槛重筛池子（拉实时K线评估流动性/波动）+ 重建行业指数，
    耗时约1~3分钟
  · 重建后到「今日机会」点「▶ 扫描」重新扫描即生效
  · 市场行情变化后，旧池子会漏掉新走强的股票，建议每月重建一次
【五、数据说明】
  · 数据来自东方财富/腾讯公开接口，免费、无需注册
  · 需要联网才能获取行情
  · 自选股、今日机会等数据保存在本文件夹内（json文件），
    卸载时删除整个文件夹即可
【六、常见问题】
  Q: 提示 Python not found / 未检测到 Python
  A: 重新运行 Python 安装包，勾选 "Add Python to PATH"
  Q: 页面行情显示"加载失败"
  A: 检查网络；数据接口偶尔抖动，点 K线图下"重试"即可
  Q: 为什么今日机会是空的？
  A: 大盘环境偏弱时（评分低于阈值）会空仓不推荐，属正常保护；
     可到「设置」把市场环境模式调为「进取」再扫描查看
  Q: 想手机/云上访问
  A: 需要部署到服务器，见云端部署包(deploy/install.sh)
【七、在线更新（免重新安装）】
  以后每次优化，你只需：
  1. 打开软件 → 右上角「检查更新」
  2. 发现新版本 → 点「立即更新」
  3. 提示完成后关闭窗口重新启动，即是最新版
  首次使用需按「在线更新说明.txt」配置一次 GitHub 仓库更新源。
